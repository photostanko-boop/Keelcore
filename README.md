 UCM B2B Antivirus Gateway (UCM B2B), a lightweight, offline-capable security agent for Windows desktop environments. The system operates as a continuous web and file risk monitor without reliance on signature databases, cloud connectivity, or machine-learning inference engines. Protection is achieved through a four-stage structural pipeline: load and rate analysis, URL lexical pattern scoring, redirect chain integrity verification, and file-level sandbox inspection including archive shallow analysis and magic byte mismatch detection. The system runs as a Windows tray application consuming approximately 0.2% of system RAM. This architecture represents a structural rather than statistical approach to threat detection, in which a file or network interaction is evaluated by its internal consistency and topological properties rather than by resemblance to previously catalogued threats.
